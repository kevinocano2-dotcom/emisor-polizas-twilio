CARTERAPRO — PERSISTENCIA DE MENSAJES

- Esta versión NO usa Cloud Firestore.
- Todos los datos del backend se guardan con Firebase Realtime Database (Admin SDK).
- Si FIREBASE_DATABASE_URL no existe, se deriva automáticamente desde project_id del Service Account.
- Los chats nuevos se guardan por teléfono en: chat_messages/{telefono}/{messageId}
- Los mensajes con SID de Twilio son idempotentes: una resincronización no los duplica.
- Inbox y chat pueden reconstruir mensajes desde los Message Logs de Twilio.
- El Inbox sincroniza Twilio al abrirse (máximo una vez por minuto) y tiene botón “↻ Twilio”.
- El chat completo sincroniza el teléfono al abrirse.
- Un fallo aislado de RTDB ya no desactiva Firebase para todo el arranque.
- Se mantiene respaldo local temporal solo como última contingencia.

Variables que ya deben existir:
FIREBASE_SERVICE_ACCOUNT_JSON
TWILIO_ACCOUNT_SID
TWILIO_AUTH_TOKEN
TWILIO_WHATSAPP_FROM
ADMIN_NOTIFY_NUMBERS

FIREBASE_DATABASE_URL es opcional si el Service Account incluye project_id.
