CARTERAPRO MENSAJERÍA V5

1. El bot ya NO repite el menú ante cada respuesta del prospecto.
2. Primer contacto: presenta CarteraPro una sola vez.
3. Pregunta libre no reconocida: manda una sola confirmación, pasa a atención humana y pausa el bot 12 h.
4. Si Kevin responde desde el Inbox, el bot se pausa 12 h automáticamente para esa conversación.
5. Para reactivar el bot: el cliente puede escribir CARTERAPRO, MENU CARTERAPRO o BOT.
6. Mensajes como OK / GRACIAS / LISTO no disparan otra respuesta automática.
7. Cada mensaje nuevo avisa al administrador; las ráfagas se agrupan para no saturar.
8. La alerta incluye:
   - responder desde CarteraPro con el mismo número Twilio;
   - responder desde WhatsApp personal;
   - abrir Inbox.
9. Twilio Message Logs se sincronizan automáticamente cada 2 minutos y al iniciar Render. Si un webhook o RTDB falla temporalmente, el historial puede reconstruirse desde Twilio.
10. Backend de aplicación: solo Firebase Realtime Database. No Cloud Firestore.
